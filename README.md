# FakeLock (网吧式半透明假锁桌面)

> 专门为 **Roblox Studio** 及 AI 自动化（如 Codex / computer-use / PyAutoGUI / MCP 自动化测试）设计的**轻量半透明防误触挂机锁**。支持**后台托盘常驻**与**全局快捷键随时呼出**。

---

## 解决的核心痛点

在进行 Roblox Studio 实机测试（Play Solo / Run 模式）时：
1. **不能使用 Windows 官方锁屏（Win+L）**：一旦系统进入锁定桌面，DWM 桌面窗口管理器会暂停/降频 DirectX 渲染管线，导致 Roblox Studio 画面冻结，且无法接收模拟键鼠事件。
2. **人离开电脑需防止误触**：离开座位挂机跑测试时，需要有一层明显的视觉遮罩挡住屏幕，既能展示电脑处于“锁定/挂机中”，又能防止周围人员或猫咪误触键鼠干扰测试。
3. **随用随呼出，常驻后台不打扰**：日常开机或启动后自动隐退到 Windows 系统托盘（0% CPU 占用），离开电脑时按快捷键（默认 **`Alt + L`**）即可秒级锁定，回来输入密码后自动退回托盘，支持全天反复循环使用。
4. **AI 自动化与真人操作精准分离**：
   - **AI 操作 100% 放行**：Codex / 自动化脚本注入的模拟键鼠（带 Windows `LLKHF_INJECTED` / `LLMHF_INJECTED` 标记）完全无阻穿透，Roblox Studio MCP/WebSocket 接口通信完全不受影响。
   - **真人操作精准拦截**：非注入物理按键与误点击全部被拦截，仅可在中间卡片输入密码解除锁定。

## 视觉与交互特性（网吧挂机锁风格）

- **纯黑息屏与半透明双模式**：
  - 🌙 **纯黑息屏模拟（类似真锁屏熄屏）**：锁定后整屏全黑并隐藏鼠标指针与卡片，外界看就像显示器关闭休眠；按下任意键或晃动鼠标秒级“点亮唤醒”浮现解锁卡片；无操作 15 秒再次自动复黑。
  - 🪟 **半透明暗色磨砂遮罩**：若关闭黑屏模式（`BlackScreen=false`），人眼可直接透过 55% 遮罩看到 Roblox Studio 后台持续渲染。
- **精致科技感悬浮卡片**：
  - 🛡️ **清晰状态说明与动态看板**：醒目标记测试状态与防误触提示，支持通过 `-notice` 随时动态刷新。
  - 🔒 **密码输入框与解锁按钮**：支持输入字母、数字及各类常用标点符号，按 Enter 键快速解锁；输错密码时具有卡片震动与红字警示反馈。
  - 🔕 **纯净去敏**：去除公开的挂机计时与按键提示，防止他人看到快捷键绕过锁屏，卡片尺寸自适应收紧（280px 高度）。
- **系统托盘与全局快捷键**：
  - 🚀 **全局热键随时锁定**：按 **`Alt + L`**（可在 `config.ini` 自定义）立即全屏锁定。
  - 🖱️ **双击托盘图标锁定**：鼠标双击右下角托盘图标即可立即进入锁定状态。
  - 📋 **托盘右键菜单**：支持手动“立即锁定”、“重新加载配置”、“退出程序”。
- **截图豁免支持（Windows 10/11 原生）**：
  - 遮罩窗口启用了 `WDA_EXCLUDEFROMCAPTURE`（可配置），使得物理屏幕上呈现半透明锁屏，而 AI 代理通过 GDI / DXGI / 截图工具抓取桌面时，系统会自动剔除遮罩，让 AI 看到 100% 原始、未受调色干扰的高清游戏渲染图。

## 快速使用

### 1. 启动 FakeLock
- **方式一（双击启动）**：双击运行目录下的 `run.bat`。程序启动后常驻系统托盘，右下角弹出就绪气泡提示。
- **方式二（命令行启动）**：
  ```cmd
  FakeLock.exe
  ```

### 2. 呼出假锁桌面（三种方式）
1. **全局快捷键**：在任何应用界面下按下 **`Alt + L`**。
2. **双击托盘图标**：双击右下角蓝绿色的锁屏托盘图标。
3. **命令行呼出**：双击运行 `lock.bat`，或在终端执行：`FakeLock.exe -lock`。

### 3. 解除锁定（四种方式）
1. **输入密码解锁**：在中间悬浮卡片的密码框中输入密码（默认密码：`1234`），按 **Enter** 回车或点击“解除锁定”按钮，假锁自动收回托盘后台。
2. **Win+L 系统锁屏自动解除**：当您按下系统原生的 **`Win + L`**（或从开始菜单锁定、系统空闲自动锁屏）时，FakeLock 会自动解除全屏假锁退回系统托盘，让渡给 Windows 原生锁屏，避免登录系统后还要再次解锁假锁。
3. **隐形紧急热键**：在任意时刻按下隐藏快捷键 **`Ctrl + Shift + Alt + F12`**（屏幕上不作提示，属于防误锁的隐形兜底后门），即可直接解除假锁退回托盘。
4. **命令行一键解除**：双击运行 `unlock.bat`，或在终端执行：`FakeLock.exe -unlock`。

### 4. 彻底退出程序
- 右键点击右下角托盘图标 -> 点击“❌ 退出程序”；
- 或双击运行 `quit.bat`；
- 或在终端执行：`FakeLock.exe -quit`。

## 配置文件说明 (`config.ini`)

程序首次运行时会自动在同级目录下生成 `config.ini`：

```ini
[Settings]
; 解锁密码（默认: 1234）
Password=1234

; 遮罩不透明度（0.10 ~ 0.95，推荐 0.55 即 55% 半透明，数值越小越透）
Opacity=0.55

; 悬浮卡片主标题文字
Title=Roblox Studio 实机挂机测试中

; 提示说明文字
Notice=AI 正在前台渲染并操作测试，物理键鼠已锁定

; 是否对 AI 截图豁免（true: AI 截图完全过滤遮罩，直接获取游戏原生高清画面；false: 截图包含遮罩）
ExcludeFromCapture=true

; 呼出锁屏的全局快捷键（支持 Ctrl, Alt, Shift, Win 与按键组合，如 Alt+L、Ctrl+Alt+L、Win+Alt+L）
LockHotkey=Alt+L

; 启动时是否立即锁屏（true: 启动后立即上锁; false: 启动后常驻托盘就绪，等待快捷键或双击呼出）
StartLocked=false

; 是否启用黑屏息屏模式（true: 锁屏后整屏全黑模拟熄屏，检测到物理键鼠动作才点亮；false: 直接显示半透明悬浮卡片）
BlackScreen=true

; 唤醒点亮后，无操作再次自动黑屏的秒数（0 表示点亮后不自动重黑，默认 15 秒）
WakeTimeout=15
```

## 命令行常用参数

| 参数 | 缩写 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `-lock` | - | - | 向正在运行的后台托盘发送信号，立即呼出假锁 |
| `-unlock` | - | - | 向正在运行的实例发送信号，立即解除锁定并收回托盘 |
| `-notice <msg>` | `-n`, `-status` | - | 向运行中的锁屏动态广播最新说明文本（支持实时看板更新） |
| `-black` | `-blackscreen` | - | 强制启用黑屏息屏模式 |
| `-noblack` | - | - | 强制关闭黑屏息屏模式（采用传统半透明遮罩） |
| `-waketimeout <s>` | - | `15` | 设置点亮后无操作再次黑屏的等待秒数（0 表示不自动复黑） |
| `-quit` / `-exit` | - | - | 向正在运行的实例发送信号，彻底退出托盘进程 |
| `-now` | - | - | 启动时强制立即锁定（无视 StartLocked 配置） |
| `-password <pwd>` | `-p` | `1234` | 设置本次运行的解锁密码（支持常用标点符号与特殊字符） |
| `-opacity <val>` | `-o` | `0.55` | 设置遮罩不透明度（`0.10` 至 `0.95`） |
| `-noexclude` | - | `false` | 禁用截图豁免（使截图包含半透明遮罩） |

## 重新编译源码

本项目使用 Windows 自带的 C# 编译器（无需安装任何 Visual Studio、.NET SDK 或第三方运行时）：

- 双击运行 `build.bat` 或在终端执行：
  ```cmd
  C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /target:winexe /optimize+ /platform:anycpu /r:System.dll,System.Windows.Forms.dll,System.Drawing.dll /out:FakeLock.exe FakeLock.cs
  ```
  即可在 1 秒内生成约 20KB 的纯绿色单文件 `FakeLock.exe`。
